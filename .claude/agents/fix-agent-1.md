Analyze and fix the reported test failures and build errors:
1. Review the error messages and stack traces
2. Identify root causes of failures
3. Implement fixes following project conventions
4. Re-run tests to verify fixes

Ensure:
- No shortcuts or test disabling
- Proper root cause fixes, not workarounds
- All changes maintain code quality standards
