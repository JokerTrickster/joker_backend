## Environment Variables

### GetEnv Function
Centralized environment variable retrieval with default values.

**Location**: `shared/utils/env.go`

**Usage**:
```go
import "github.com/JokerTrickster/joker_backend/shared/utils"

// Get environment variable with default
dbHost := utils.GetEnv("DB_HOST", "localhost")
port := utils.GetEnv("PORT", "8080")

// Empty string default
apiKey := utils.GetEnv("API_KEY", "")
```

**Benefits**:
- Consistent default value handling
- Single source of truth
- Easy to test and mock

## Request ID Generation

### GenerateRequestID Function
Cryptographically secure request ID generation.

**Location**: `shared/utils/requestid.go`

**Usage**:
```go
import "github.com/JokerTrickster/joker_backend/shared/utils"

// Generate a unique request ID
reqID := utils.GenerateRequestID()
// Returns: "a3f5b2c1d4e6f7a8b9c0d1e2f3a4b5c6"

// Already integrated in middleware
// No manual usage needed in most cases
```

**Technical Details**:
- Generates 32-character hex string (16 bytes)
- Uses `crypto/rand` for security
- Fallback to timestamp if crypto/rand fails (extremely rare)
- Prevents request ID collision attacks

**Automatic Usage**:
Request IDs are automatically generated by the middleware:
```go
// Already applied in RequestLogger and RequestID middleware
e.Use(middleware.RequestLogger())
e.Use(middleware.RequestID())
```

## Body Size Limiting

### Body Size Limit Middleware
Prevent DoS attacks from excessively large request bodies.

**Location**: `shared/middleware/bodysizelimit.go`

**Usage**:

#### Default Limit (10MB)
```go
import "github.com/JokerTrickster/joker_backend/shared/middleware"

// Apply 10MB limit to all routes
e.Use(middleware.DefaultBodySizeLimit())
```

#### File Upload Limit (100MB)
```go
// Create a group for file uploads with higher limit
uploadGroup := e.Group("/api/v1/upload")
uploadGroup.Use(middleware.FileUploadBodySizeLimit())
uploadGroup.POST("/file", handleFileUpload)
```

#### Custom Limit
```go
// Apply custom 5MB limit
e.Use(middleware.BodySizeLimit(5 << 20))

// Common size constants
const (
    KB = 1 << 10  // 1024 bytes
    MB = 1 << 20  // 1024 * 1024 bytes
)

// 2MB limit
e.Use(middleware.BodySizeLimit(2 * MB))
```

**Constants**:
```go
DefaultMaxBodySize  = 10 << 20   // 10 MB
MaxFileUploadSize   = 100 << 20  // 100 MB
```

**Error Response**:
When limit exceeded:
- HTTP Status: `413 Request Entity Too Large`
- Automatic error response from Echo

**Best Practices**:
1. Apply default limit globally
2. Use specific limits for upload endpoints
3. Set limits based on your use case:
   - API endpoints: 1-10 MB
   - File uploads: 10-100 MB
   - Media uploads: 100+ MB (custom)

## Configuration Validation

### Config.Validate() Method
Fail-fast configuration validation on application startup.

**Location**: `shared/config/config.go`

**Automatic Usage**:
```go
import "github.com/JokerTrickster/joker_backend/shared/config"

// Validation happens automatically in Load()
cfg, err := config.Load()
if err != nil {
    // Configuration invalid - application will not start
    log.Fatalf("Configuration error: %v", err)
}

// If we reach here, configuration is valid
```

**Validation Rules**:

#### Development Environment
- Accepts defaults for all values
- No password required
- Default CORS origins allowed

#### Production Environment (Strict)
- **Required**:
  - `DB_HOST`
  - `DB_PORT`
  - `DB_USER`
  - `DB_NAME`
  - `DB_PASSWORD` (production only)
  - `CORS_ALLOWED_ORIGINS` (production only)
- **LOG_LEVEL**: Must be one of: `debug`, `info`, `warn`, `error`

**Example Environment Setup**:

Development:
```bash
ENV=development
# Minimal config - defaults will be used
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_NAME=dev_db
# DB_PASSWORD can be empty
# CORS_ALLOWED_ORIGINS uses defaults
```

Production:
```bash
ENV=production
DB_HOST=prod-db.example.com
DB_PORT=3306
DB_USER=prod_user
DB_PASSWORD=secure_password_here     # REQUIRED
DB_NAME=prod_db
CORS_ALLOWED_ORIGINS=https://app.example.com  # REQUIRED
LOG_LEVEL=info
```

**Error Handling**:
```go
cfg, err := config.Load()
if err != nil {
    // Example error message:
    // "configuration validation failed:
    //  DB_PASSWORD is required in production
    //  CORS_ALLOWED_ORIGINS must be explicitly set in production"

    // Handle error - log and exit
    log.Fatalf("Configuration error: %v", err)
}
```

**Manual Validation**:
```go
// Validate after modifying config
if err := cfg.Validate(); err != nil {
    log.Fatalf("Invalid configuration: %v", err)
}
```

## Database Migrations

### Internal Improvements
The migration package now uses a shared helper function internally for better maintainability.

**Location**: `shared/migrate/migrate.go`

**Usage** (unchanged):
```go
import "github.com/JokerTrickster/joker_backend/shared/migrate"

// Run migrations
err := migrate.Run(db, migrate.Config{
    MigrationsPath: "./migrations",
    DatabaseName:   "my_database",
})

// Rollback last migration
err := migrate.Down(db, migrate.Config{
    MigrationsPath: "./migrations",
    DatabaseName:   "my_database",
})

// Get current version
version, dirty, err := migrate.Version(db, migrate.Config{
    MigrationsPath: "./migrations",
    DatabaseName:   "my_database",
})
```

**Internal Changes**:
- Extracted `newMigrateInstance` helper function
- Reduced code duplication from 176 to 120 lines
- No API changes - fully backwards compatible

#### Setup Middleware Stack

```go
// Load and validate configuration
```

```go
    log.Fatal("API_KEY environment variable is required")
```

## Troubleshooting

### Configuration Validation Fails

**Problem**: Application won't start with configuration error

**Solution**:
1. Check error message for missing variables
2. Set required environment variables
3. For production, ensure `DB_PASSWORD` and `CORS_ALLOWED_ORIGINS` are set

### Body Size Limit Too Small

**Problem**: Valid requests rejected with 413 error

**Solution**:
```go
// Increase limit for specific routes
uploadGroup := e.Group("/upload")
uploadGroup.Use(middleware.BodySizeLimit(50 << 20)) // 50 MB
```

### Request ID Not Found

**Problem**: Request ID missing in logs

**Solution**:
```go
// Ensure middleware is applied
e.Use(middleware.RequestID())
e.Use(middleware.RequestLogger())
```

## Performance Notes

### Request ID Generation
- **Performance**: ~0.0001ms per ID (crypto/rand is fast)
- **Memory**: 32 bytes per ID
- **Overhead**: Negligible for typical applications

### Body Size Limiting
- **Performance**: Minimal overhead (Echo's built-in middleware)
- **Memory**: No additional memory overhead
- **Behavior**: Stops reading at limit - prevents memory exhaustion

### Configuration Validation
- **Performance**: One-time cost at application startup
- **Impact**: <1ms for typical configurations
- **Benefit**: Prevents runtime failures

## Best Practices

1. **Always validate configuration on startup**
   ```go
   cfg, err := config.Load()
   if err != nil {
       log.Fatalf("Configuration error: %v", err)
   }
   ```

2. **Apply body size limits globally**
   ```go
   e.Use(middleware.DefaultBodySizeLimit())
   ```

3. **Use crypto-secure request IDs** (automatic with middleware)
   ```go
   e.Use(middleware.RequestID())
   ```

4. **Set explicit production configuration**
   - Never use defaults in production
   - Always set DB_PASSWORD
   - Always configure CORS explicitly

5. **Test configuration changes**
   ```bash
   ENV=production DB_HOST=test DB_PORT=3306 DB_USER=test \
   DB_PASSWORD=test DB_NAME=test CORS_ALLOWED_ORIGINS=https://test.com \
   go run cmd/server/main.go
   ```
